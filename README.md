# OpenDX collector

Public runtime for the OpenDX bookmarklet. Maintained by OpenDX-ops.

Stable URL: https://opendx-ops.github.io/collector/v1.js

The saved bookmark loads the current runtime on every execution. This repository contains code only; no player records, credentials, cookies, or private configuration are published.

Generated from the private OpenDX application with `npm run publish:collector`. Deployments run through GitHub Pages after a push to main.
